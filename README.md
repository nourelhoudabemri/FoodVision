# FoodVision – Food Recognition and Recipe Recommendation (Stay tuned)

## Project Overview

FoodVision is a Computer Vision project designed to recognize food dishes from images using Deep Learning techniques. The system analyzes an uploaded image, predicts the food category, and provides the corresponding recipe, including ingredients and preparation instructions.

The project combines image classification and recipe recommendation to create a simple and interactive food recognition application.

## Objectives

- Recognize food dishes from images.
- Develop and train an image classification model.
- Explore and compare different Deep Learning approaches.
- Improve classification performance through experimentation.
- Provide recipes, ingredients, and preparation instructions based on the predicted food category.
- Develop a user-friendly interface for interacting with the system.

## Technical Approach

The project will follow these steps:

1. Collect and explore the dataset.
2. Preprocess and prepare the images.
3. Implement a baseline Convolutional Neural Network (CNN).
4. Experiment with ResNet18 using Transfer Learning.
5. Train and evaluate the models.
6. Compare the results and analyze classification errors.
7. Integrate the best-performing model into a web application.

## Technologies

- **Programming Language:** Python
- **Deep Learning:** PyTorch, Torchvision
- **Computer Vision:** Pillow, OpenCV
- **Web Application:** Streamlit
- **Data Analysis:** NumPy, Pandas
- **Evaluation:** Scikit-learn, Matplotlib
- **Version Control:** Git, GitHub

## Model Evaluation

The models will be evaluated using the following metrics:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

A comparison between the baseline CNN and ResNet18 will be conducted to analyze their performance.

## Expected Results

The final application should allow users to:

- Upload a food image.
- Obtain the predicted food category.
- View the prediction confidence score.
- Access the corresponding recipe.
- View ingredients and preparation instructions.
